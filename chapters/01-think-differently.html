CHAPTER 01

Think Differently

Programming does not have to mean a list of instructions.

Use → to advance · Esc for slide overview

What if we described a world?

Instead of saying how to compute something, we can describe relationships and ask questions.

A tiny world

likes(ada, tea).
likes(ben, coffee).
likes(ada, music).

Each statement is a fact.

Ask a question

?- likes(ada, tea).
true.

?- likes(ben, tea).
false.

Assuming this is the complete program, the second query cannot be proven.

Your first challenge

Which fact would you add to make this query succeed?

?- likes(ben, music).

The big idea

Prolog programs describe what is known. Queries ask what follows from that knowledge.
